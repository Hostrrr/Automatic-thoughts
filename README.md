# Мысли — дневник автоматических мыслей

Нативное iOS 17+ приложение (SwiftUI + SwiftData) для КПТ-дневника: быстрый захват мысли и последующее дозаполнение.

## Открыть проект

1. Откройте `AutomaticThoughts.xcodeproj` в Xcode 15.4+ (лучше Xcode 16 / 26).
2. Выберите свой Team в Signing & Capabilities.
3. Симулятор: iPhone (компактный список) и iPad (две колонки).
4. `Cmd+R`.

Display name: **Мысли**. Bundle ID: `com.hostrrr.AutomaticThoughts`.

## Что проверить в симуляторе

1. Приложение запускается, вкладка «Дневник», пустой список и кнопка `+`.
2. `+` открывает быстрый захват. Без мысли «Сохранить» неактивна. После сохранения запись появляется в секции «Черновики» с бейджем «Дозаполнить».
3. Тап по черновику открывает полную форму. «Сохранить» снимает черновик — запись переезжает в «Записи».
4. Свайп влево удаляет запись.
5. Shortcuts: действие «Новая мысль». Запуск открывает захват и на cold start, и когда приложение уже открыто. URL `thoughts://capture` — то же самое.
6. iPad (или широкий холст): список слева, форма справа.

Виджеты, Control Center, синхронизация и графики — следующая итерация.
